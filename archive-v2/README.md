# YEON — The Question Room (Archive 2.0)

This is a **frontend-only research UX concept**, preserving the seven working YEON prototype tools. The official landing page and V4 remain unchanged.

Live preview: https://subhana2004.github.io/yeon/archive-v2/

The new Explore screen includes an editorial question-led archive, a dynamic laboratory reading stage, three perspectives (question, methods, limits), live search and field filters, keyboard list navigation, randomized discovery, and a persistent two-lab comparison shelf connected to the existing Compare tool. On mobile, the selected research story precedes the index.

**All eight sample laboratories, publications, opportunities, and their connections are fictional demonstration fixtures.** This version does not verify real Korean laboratories or provide a backend.

Local headless Chromium tests: viewport widths 1440, 1024, 760, 390 and 320 px without horizontal overflow or JavaScript errors; search, filtering, stage selection, lens switching, saving two labs, comparison navigation, keyboard arrows, all seven feature screens, dark mode and reduced-motion behavior passed. Public-page visual QA is separate.

Design guidance checked: Anthropic frontend-design, Impeccable, Jakub Krehel’s interface skills, Emil Kowalski’s animation-review skill, and UX Usability Foundations. Git clone was blocked in this environment, so upstream skills were reviewed through GitHub source rather than installed.
