# YEON — Research Atlas V2 (frontend-only)

Live preview: https://subhana2004.github.io/yeon/app-v2/

YEON Atlas V2 is a self-contained, static, editorial research workspace. It features an interactive two-pane laboratory index, source-style Lab DNA dossiers, Lab Compare lenses, a selectable Constellation, a followable Radar feed, Open Doors notice panels, Fit Lens topic matching, Research Face-Off, and Ctrl/Cmd+K quick navigation.

**Every lab, institution, paper, research relationship, opportunity and update is fictional sample data.** There is no connected backend, real university affiliation, authentication, monitoring, admissions prediction or actual job listing. This is a design and interaction prototype only.

No build dependencies or API keys are required. HTML, CSS and JS are in one `index.html` for GitHub Pages compatibility. Fonts are optional Google Fonts with system fallbacks. The older `/app/` frontend is preserved for comparison.
