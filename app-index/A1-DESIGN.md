# YEON A1 — Midnight / Pearl / Lime

A dedicated visual experiment derived from the user's golf-design reference, studying its deep midnight teal (`#0B3048`), soft pearl (`#F2F0E9`), neon lime (`#B9F12F`), confident typography, atmospheric depth, restrained controls, and clear hierarchy. It does **not** reproduce the golf-ball subject, golf island, imagery, composition or branding.

This experiment builds on the working seven-tool YEON Index branch. The Explore hero uses original, hand-authored SVG research pathways and a functional feature rail. Remaining routes keep existing behaviours while adopting a unified visual token system. The demo lab dossiers are fictional; the site does not claim a live verified research feed.

Separate Git branch: `design/yeona1-midnight`. Production `main` and PR #16 remain untouched.
