# YEON V4 Finesse — Alignment & Palette Study

This is an **independent UI/UX refinement preview** of the original [YEON Research Reader V4](https://subhana2004.github.io/yeon/app-v4/). It does not replace the original, the landing page or the Archive 2.0 experiment.

## Goal
Tighten the small details that make the difference between a good page and a cohesive research product:

- One warm-white and sage palette shared by the hero, field choices, archive, and dossier
- Aligned outer gutters, panel spacing, typography, and grouping
- A gentler green for selected states and fewer competing accent tones
- Slightly more consistent button/input shapes and hover states
- Retained keyboard focus, reduced-motion behavior, original content, and existing seven-tool frontend demonstration

## Test coverage

Local Chromium tests passed at 1440, 1024, 760, 390, and 320px: Discover / Investigate mode switch, research-field selection, reading-lens selection, page rendering, JavaScript error collection and horizontal overflow checks. These are simulated browser tests with unavailable external Google Fonts blocked; public device testing remains advisable.

## Integrity

All lab and paper records are fictional examples. This is frontend-only—no verified live research data, backend, accounts, or real opportunities.

Source includes the original V4 self-contained page and the focused **V4 Finesse** style overrides for easy review.
